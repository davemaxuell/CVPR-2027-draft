# Assignment 6 — independent implementation interventions

Saved 2026-10-23 before reading any other assignment, worker suggestions, or results. Read inputs: the review brief and all ten original files under Research Approach. These are independent engineering hypotheses, not established contributions or validated improvements.

1. **A replayable branch tape as the central experimental object.** Implement an immutable record of the actual prefix, canonical first action, first real next observation, frozen-policy continuation, evaluator result, and all policy/configuration hashes. Derive every scorer/world-model training view from the same tape. Begin with replay-from-reset instead of deep-copying opaque Habitat and model caches. This turns most experiments into offline feature jobs and exposes exactly which experiment differs in history, budget, or privilege.
2. **A paired action-contrast representation.** Test a cheap residual interface (predicted next DINO patches minus current patches), alongside the full next-feature interface with identical real context. One-step changes are often small; the residual could concentrate capacity on direction/collision-relevant changes and reduce action-identity shortcuts. Include a null/current-view control and within-root permutation. Residuals are a proposed ablation, not a replacement for the original agreed comparison or a novelty claim.
3. **A measured teacher-to-small-predictor screen.** Before full CDiT adaptation, cache actual next features and fit a tiny commanded-action residual predictor as an engineering lower bound. If this plus a scorer matches a large dynamics model at matched time, the expensive visual generation path has not earned its cost. Retain the four agreed WM families as named comparisons; the tiny predictor is a screening ablation, not a silently substituted fifth main family.
4. **Separate observation handling from decision handling.** Give each backbone adapter one pure real-observation transition that returns base action and context, plus an explicit commit of the actual chosen action. Make imagined futures unable to call the observation transition. Use cache-free prefix replay initially and add KV-cache acceleration only after action/feature equivalence checks. This makes forced actions and branch restoration falsifiable.
5. **Offline stage separation for the 8 GB target.** Collect branches with the actor and simulator, encode/capture features in separate jobs, train only the scorer on frozen tensors, then run WM variants sequentially rather than co-resident. Quantify cache bytes and stage peaks. This preserves the comparison while separating training feasibility from full online inference feasibility.
6. **Spend expensive prediction only at decision-sensitive roots.** As a later deployment ablation, train a small gate from real context to predict whether candidate utility gaps might justify a WM call; default to the frozen actor otherwise. Train the gate on measured branch tapes and report recall of beneficial overrides, total latency, and matched-runtime results. Do not use privileged future outcomes online. This could make a weak but useful model practical, but conditional compute needs its own fair control.
7. **Use cheap contradiction tests as release gates.** Require deterministic branch replay; forced-action/cache agreement; STOP with zero WM calls; no reference-coordinate access in model inputs; scene-group disjointness; and identical first-step transition across repeated roots. Tests should validate integration contracts rather than claim language competence. Run the real-next versus no-future comparison before architecture expansion.

Preferred minimal order: make one actor adapter and replayable root collection correct; prove real-next information improves held-out branch decisions; fit a small DINO-family model; only then pay for diffusion and extra policy ports. Preserve all three locked backbones and four agreed WM options in the registry and staged evaluation plan. None of these suggestions establishes paper novelty or a complete 8 GB fit.
