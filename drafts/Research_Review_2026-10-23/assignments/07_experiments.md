# Assignment 7 — Falsification and experimental design

2026-10-23 · Proposed protocol, not CE results · Original materials unchanged

**Decision:** first buy reliable branch labels and a strong direct-value control. The cheapest informative sequence is replay integrity → candidate opportunity → actual-next-view versus no-future scoring → predicted futures versus controls → one conditional objective → closed-loop and resource validation. The existing 64-root/eight-episode pilot is a collector debugging exercise. It cannot establish a useful training-set size, statistical power, a navigation gain, or an 8 GB fit.

## 1. Question, estimands and claims that can fail

[Proposed] Primary question: for one trained and frozen CE actor, do action-conditioned predicted next features improve held-out action choice and complete navigation **beyond a direct action-value model with the same labels and allowed history**, under identical sensing, primitive actions and one-action replanning?

[Specification] Preserve three actor trials and four WM families. Start with SmolVLM2 and the DINO family for cost, then retain OneVision, Qwen3-VL and transferred/fresh CDiT as recorded, gated comparisons. This staging does not delete them. The primary result is conditional on the chosen actor checkpoint; one actor cannot establish backbone-independent benefit.

Use the original root target `U_t=.70 S+.30 N-.01 n_t/B-.02 c_t/B`, with official whole-path nDTW and the original remaining budget. Record all components. Complete episodes report `J=.70 S+.30 N-.01 n_total/B-.02 c_total/B`, SR, SPL, nDTW, SDTW, navigation error, actions, path length and collisions separately. A utility gain does not imply an SR gain or satisfaction of each instruction clause.

| Hypothesis | Observation that defeats the proposed claim at this stage |
|---|---|
| H1: primitive alternatives offer usable improvement | Independent-seed selected-candidate lift is too small, despite precise labels. |
| H2: the scorer can exploit a next observation | Actual-next-view scoring cannot improve on base/direct value with adequate data and precise evaluation. This localizes a scorer/information issue; it does not refute every world model. |
| H3: prediction has useful representation value | Predicted features fail to beat the full-history direct-value control at matched data; or a current-view copy/cheap predictor/distilled direct model explains the gain. |
| H4: one added objective corrects relevant prediction errors | Training loss improves but held-out actual-label choice and episodes do not, or uniform/simple weighted prediction controls match it. |
| H5: the system is useful in closed loop and at the target cost | Offline lift disappears under repeated overrides, or the gain disappears against a stronger direct model at the same measured cost. |

[Deduction from A2/A3] Exact full-history `Q_ref` can support repeated policy improvement. A different deployed continuation is therefore not itself a contradiction. The operational risk is inaccurate values at reranker-visited histories. Actual next views are a **privileged diagnostic**, not a guaranteed numerical ceiling for finite trained scorers. Independent imagined samples are not observations of the real future.

## 2. Freeze the experiment contract before collecting outcomes

[Proposed] Store a versioned manifest containing: code/config/checkpoint hashes; scene and episode lists; R2R/RxR revision, language/annotation role; task action identifiers, step distance/turn angle; sensors, HFOV and resolution; sliding/collision/STOP/timeout semantics; full budget; actor prompt/cache/window schedule; encoder/preprocessing and patch convention; model/data partitions; random streams; training budgets; candidate/margin rules; all exclusions. Record changed fields as a new protocol version.

**Scene separation.** Hash and group physical scene IDs shared by R2R/RxR, then allocate roughly 60%/20%/20% of CE training scenes to A/B/C, with actual counts published. A fits actor/DAgger and native dynamics; B supplies scorer-fitting branches; C selects checkpoints, margins and precision estimates. For the conditional outcome-weighted dynamics experiment, collect its outcome branches in A: do not silently use B to fit dynamics. C is development data even if split internally into tuning/audit subsets. The official unseen-scene set is untouched until the entire method and comparison list are frozen. A reduced-A actor is a pilot policy; do not present its scores as a full-training-data reproduction. Expanding to full training scenes requires a separate out-of-fold/final-training protocol and rerunning controls.

**Sampling.** Main root estimates use policy-visited episodes, selected without inspecting failures or branch outcomes. Sample episode uniformly, then up to four legal nonterminal prefix times using a recorded stratified-time sampler; average roots within episode so long routes do not dominate. Expert-prefix roots are a separate coverage stratum, never pooled into deployment lift without explicit weights. Report source, route-length, language, near-goal/STOP and collision strata; no hand-picked success examples in the primary estimate. Repeated instructions on the same underlying route share a cluster identifier.

**Input boundaries.** Model inputs contain only instruction, actual RGB/history/actions, elapsed budget and candidate command. Future pose/displacement, collision flags, reference path, goal and completed metrics live in a separate label schema inaccessible to the forward loader. Validate the boundary by removing/shuffling label-only fields and confirming unchanged predictions. Do not use those fields to construct a supposedly nonprivileged action embedding.

**Exact feature interface.** Resolve A6's inspected native DINO path (196 pixels, 14×14 patches) versus original scorer (224 pixels, 16×16 patches) before collecting feature comparisons. Select either a consistent 14×14→7×7 revision for every actual/predicted/CDiT-encoded view, or a documented compatible 16×16 path. Never resize only predicted tokens and call the adapter identity. Pin representation, grid/order, normalization and pooling across controls; a revised scorer needs its own version and contract checks.

## 3. Stages, measurements and stop rules

### E0 — Replay and deployment integrity; no learning claim

[Proposed] Once prerequisites exist, use two legal training episodes with beginning/middle/near-budget roots, then expand to the 64-root debug set. Reset and replay each real prefix three times. For deterministic execution require equal action sequence, task budget, termination flag, metric prefix, RGB hashes and base action. Compare context/features to a predeclared numerical tolerance (`atol=1e-5, rtol=1e-4` initially for FP32; a lower-precision tolerance must be measured and fixed before branch comparisons). If rendering is nondeterministic, document its range and use the stochastic protocol rather than declaring byte equality.

For each root, compare forced base action plus `pi_ref` with ordinary `pi_ref` from that root; compare cache optimization to full prefix replay; randomize branch execution order; test all canonical/Habitat action mappings; test immediate STOP and final available action; reconstruct whole-path metrics; verify rejected futures do not change persistent memory. Commit the actual forced action, discard unexecuted chunk tokens, and update memory exactly once per real observation. Inject a nonfinite prediction and verify logged base fallback. Compare native chunk and H=1 no-scorer episode behavior separately.

**Gate:** zero unexplained state/cache/action/metric mismatches and successful label/input separation. Any mismatch blocks label collection and invalidates affected tapes; fix and recollect. Passing synthetic scorer checks does not pass E0. A change in only execution schedule can be a valid baseline change but cannot count as prediction benefit.

### E1 — Candidate opportunity, without noisy-oracle optimism

[Proposed] Debug collection: **64 roots from at least eight episodes**, four branches each, including 64 immediate STOP branches and 192 movement continuations. This is the original debugging target, not training evidence. Log every exclusion, timeout, distinct outcome, best/base gap and branch length. Do not fit a 3M scorer and treat memorization here as progress.

After timing the collector, run a separate development opportunity sample: initially 128 policy-visited roots from at least 64 episodes in C, at most two roots per episode, distributed over all available C scenes. A maximum of 512 roots/256 episodes is a planning cap, not a power claim. Choose the final count from development variance and measured collection cost **before** inspecting the new sample's treatment results. If available scene/episode counts or the budget cannot resolve the prespecified effect, report inconclusive rather than collecting thousands of correlated roots.

Measure: base value; selected-candidate lift defined in §4; label uncertainty and action-gap distribution; all-failure/all-success/tied roots; alternative-success frequency; STOP dominance; geometric-distance versus utility-order disagreements; branch cost. Also report best-realized-outcome maximum, labeled explicitly as a debugging statistic.

**Gate:** a lower confidence bound above zero and a point estimate at least 0.02 utility units for independent-evaluation selected-candidate lift earns E2. An upper bound below 0.02 stops expensive WM expansion for this H=1/continuation configuration. Wide intervals are inconclusive. These thresholds are planning assumptions, not established CE norms. Near-zero opportunity under a weak actor can mean its continuation fails from every alternative; it does not establish that longer candidates, another actor or a different target cannot work. Any such pivot needs fresh labels and a revised scope.

### E2 — Can a small evaluator use actual futures?

[Proposed] Cache frozen features and train only scorers. Begin a learning curve on B at 128, 256, then 512 distinct roots (at least 32/64/128 episodes, maximum four roots per episode), using three optimization seeds. These are exploratory tiers; none is presumed sufficient. A conditional cap of 2,048 roots/512 episodes is allowed only in the frozen resource plan. Evaluate the same fixed C roots at each training tier; this is development, not final confirmation. Replay memory with current parameters; cache raw frozen features, never stale learned memory states.

Primary paired controls:

1. `B0`: frozen actor, H=1, no scorer.
2. `Q-null`: same scorer capacity, actions, instruction, context, recurrent history, labels, optimizer, steps and model-selection budget; learned null future tokens. Keep STOP's current-view rule identical.
3. `Q-real`: separately trained matched scorer with actual first-next features and the same branch outcomes. This measures privileged feature usefulness, not a deployable policy.

The WM and direct-Q pathways must have equal **access to all allowed real frames/actions**: if the WM sees recent raw features missing from `q_t/M_t`, give Q-null an explicit recent-history path and account for its parameters. Otherwise a win can mean better history access. Add a small pooled-feature MLP and remove auxiliary heads only after these primary controls; they test scorer complexity, not the predictive hypothesis.

Metrics: paired selected-action lift versus B0 and Q-null; regret only with the qualifications in §4; action ordering outside a declared 0.01 utility near-tie band; success/collision Brier score and reliability bins with counts; STOP false positives/negatives; calibration by scene/language/root source. Report learning curves and seed variation. Inspect high-confidence errors in raw real history: cue observable but lost, cue present but misused, or cue unavailable. Do not invent instruction negatives.

**Gate:** Q-real must beat B0 and Q-null in development by a point estimate of at least 0.01 utility with an interval excluding zero before large WM expansion. If direct Q already matches it precisely, the next observation has not earned a costly experiment for this scorer. If neither learns and learning curves are still rising or intervals wide, call it insufficient data/capacity evidence, not a scientific rejection. A finite Q-real loss is not a mathematical upper bound on Q-pred.

### E3 — Does the predicted channel earn inference cost?

[Proposed] First compare architecture-matched transferred/fresh DINO dynamics with native prediction loss. Freeze them and fit a versioned scorer from equally sampled predicted sources, finishing on predicted inputs and actual return targets. A mixture of actual and predicted features is a curriculum, not proof that the two conditional regressions agree. For the family comparison hold this scorer's exact weights fixed; adding CDiT later creates a new pool/version and requires rerunning the comparisons. Separately tuned complete systems are a secondary experiment.

Compare predicted features against Q-null with matched history/data, current-view copies, and a cheap action-conditioned one-layer per-patch residual predictor fitted to the same A transitions. Retain native chunk and H=1 actor baselines. Evaluate the trained full scorer with all five nonidentity permutations of the three movement futures, keeping action IDs and STOP fixed. This is a reliance diagnostic, not a fair replacement policy. Retrain copy/null controls; a test-time null substitution alone is distribution shift.

Report selected-action lift and official metrics, feature MSE/cosine as secondary measures, actual→predicted diagnostic loss, per-WM score bias/calibration, override frequency, harmful/helpful overrides, model-seed ranking instability, failure/fallback rate and cost. On 64 prespecified C sentinel roots use 20 independent model seed sets without recollecting deterministic labels. For stochastic labels use the crossed protocol in §4. Compare one sample with mean-score aggregation of four samples at measured cost; **never select the most optimistic sample**.

Include a present-only distilled/direct value student trained with the same permissible branch data and teacher budgets if the full method shows a signal. This asks whether inference-time generation is needed. Count extra predictive pretraining/CE transitions: same scorer capacity alone does not match the whole predictive pipeline's data or compute. A stronger direct baseline may spend the measured additional budget on history/width or distillation, selected in C, with all costs reported.

**Gate:** point lift ≥0.01 utility over the strongest relevant direct/copy/cheap control with an interval excluding zero, plus correct-action degradation under future/action reassignment, earns E4. Permutation sensitivity alone is not correctness. A precise tie means predictive execution is unsupported; improved pictures, auxiliary AUC or training MSE do not rescue the claim. A gain only against the chunk baseline leaves schedule confounding unresolved.

### E4 — Exactly one conditional objective, within one WM family

[Proposed redesign, conditional on E3; aligned to frozen proposal v2] The synthesis-selected mechanism is **centered utility-residual training** in deterministic DINO prediction. It is a conditional value-aware-learning experiment, not an established new loss. Let the existing qualified frozen critic yield `s_a=Sbar(x,a,Zhat_a)`, let `y_a=Qbar_a`, and `P=I−11ᵀ/4`. Train

`L = L_native + λ (1/4) ||P(s−y)||²`.

This exactly equals an all-pairs squared utility-gap term up to normalization. Test numerical equivalence of the two implementations; do not report them as different scientific baselines. No outcome weighting, Huber variant, extra critic, alternating fit or extra online module is part of the core v2. STOP retains the current view and supplies no predictor gradient, although its centered residual affects the movement-action gradients.

Collect the added dynamics-adaptation outcome branches only in A. Reuse the E3 critic fitted in B, frozen before adaptation, and keep its weights fixed for the native/adapted comparison. **Declare the data-contract revision:** B labels influence adapted dynamics indirectly through this critic. This is legal CE training, but it is no longer strict separation of all WM learning from scorer-fitting information. Count those B labels/critic fitting costs in adaptation and grant matched controls the same union of data/teacher access. C and official unseen scenes remain excluded from fitting. If strict A-only dynamics information is required instead, a separate A-fitted qualified critic is a separately versioned protocol, not silently added to v2.

The original scorer detaches future inputs. Add an opt-in differentiable future route with frozen critic weights: require finite nonzero gradients in intended dynamics/action parameters and zero gradients in frozen critic/encoder parameters. Qualify the same critic near actual and predicted features, retain native anchoring, and inspect actual-feature versus predicted-feature errors before and after adaptation. Freezing parameters does not prevent critic exploitation. If the adapted features invalidate the critic, the candidate fails; no unreported scorer refit rescues the fixed-critic claim. A5's exact centered/Laplacian reduction means the squared gap term cannot be credited as a distinct ranking principle.

Minimal first comparisons at equal updates/data/architecture: native loss; native plus ordinary per-action utility regression through the same critic; native plus simple outcome-weighted feature prediction; proposed centered residual. Before a methodological claim, add the outcome-weighted observed-feature contrast below and the relevant MCR-style geometric-order/VaGraM-style real-feature weighting rival as specified in v2; these are comparator costs, not new contributions. Use identical initialization within each loss-comparison seed, three training seeds, the same frozen critic and identical evaluation roots. Predeclare `λ` grid `{0.1,1}` plus native `0`, normalizing auxiliary loss scale on a fixed A batch before training; give controls equal tuning budgets. Do not simultaneously add a parser, gate, ensemble, longer horizon and new memory.

**Meaningful design disagreement:** A7's preferred first objective remains the cheaper observed-feature contrast `L_native+λ Σ w_ab ||(Zhat_a−Zreal_a)−(Zhat_b−Zreal_b)||² / Σ w_ab`, because it avoids direct optimization of extrapolated critic values and the additional gradient-route qualification. Set `w_ab=min(|Qbar_a−Qbar_b|/0.1,1)` with a declared noise/near-tie filter; zero-weight roots retain only native loss. Its uniform squared version is centered feature regression, not a new principle. The coordinator selects gap-through-qualified-critic as the core hypothesis, so the experiment above follows that choice. The feature alternative remains a substantive rival even if obvious exploitation is not observed. If it or simpler per-action weighting matches the gap method, replace/drop the core extension; do not erase the disagreement or add both as nominal contributions. Both alternatives retain substantial prior-art overlap.

Measure whether held-out action ordering improves specifically where geometric deviation and actual instruction utility disagree, plus unconditional frequency of those cases. Manually curate legal route-order, detour, turn-timing and STOP cases with verified references, then report them separately from ordinary held-out episodes. Compare targeted-error correction, all-root selection lift, native prediction error, common-mode error, and closed-loop outcomes. An objective may overfit brittle downstream actor continuations; unchanged actor labels and held-out scenes expose that risk.

**Preregister the ordering diagnostic (v2 §7).** For each movement action define unnormalized actual immediate goal-geodesic progress `g_a=d_geo(p_t,goal)−d_geo(p_a,goal)` and normalized `G_a=g_a/d_step`, larger better. Pose/goal are privileged label-pipeline fields only. Freeze geodesic implementation, goal convention and action size before inspecting results. The initial geometry tolerance is **0.01 m on `g_a−g_b`**, checked against simulator precision before outcome inspection; equivalently use `0.01/d_step` on `G_a−G_b`. A strict reversal requires opposite signs of geometry and expected-utility differences, geometry magnitude over that tolerance, and utility magnitude over 0.01 with a noise interval excluding zero. Report strictly ordered-pair coverage, reversal prevalence on all ordinary sampled roots, tie-resolved cases and uncertain cases separately. LEFT/RIGHT positional ties are not reversals. STOP is excluded from movement-progress ordering and evaluated separately using official terminal criteria. An effect consisting only of turn/STOP blind spots does not earn the proposed finding.

This goal-progress diagnostic is **not an MCR reproduction**. A direct MCR comparison requires pinning its actual trajectory-deviation target, horizon, reference alignment, orientation/STOP domain and tie policy; an H=1 port must be labeled an adaptation. If a fair port is unavailable, report that limitation. Since U includes geometric nDTW and success terms, its disagreement with goal progress initially establishes only an **outcome-versus-proxy mismatch**. A language-semantic interpretation additionally requires independent valid instruction/route-stage annotations, blinded to model scores and outcomes, with annotation rules/disagreements/coverage reported. Prefer matched physical roots under distinct valid instructions, or naturally different valid stages with observable history; recompute each task's references and branch outcomes. Keep that subset separate from ordinary-root prevalence and compare the full instruction/history with prespecified neutral/reminder/history controls. Arbitrary shuffled instructions do not define valid negative tasks. If only benchmark-target mismatch is supported, leave the semantic contribution target unmet.

**Gate:** improvement over native and the simpler value/feature/weighting controls, including actual outcomes and E5, is required for the proposed remedy. If only loss decreases, stop. Any loss-name/normalization advantage alone is insufficient. The two contribution targets are a nontrivial semantic-ordering finding and an outcome-aware remedy; neither is established by defining this experiment, and both overlap prior work. The original detach remains correct for the frozen-WM baseline. Defer stochastic CDiT gap training until its expectation/variance target and gradient-through-decoder/DINO cost are separately declared; single-sample squared matching penalizes score variance as well as mean error. Preserve transferred/fresh CDiT native-objective trials. Cheap weighting of diffusion examples is a different surrogate and must not be called the same gap objective.

### E5 — Closed-loop confirmation, occupancy and full cost

[Proposed] Choose margins only on C branch data and complete C episodes. Small candidate grid `{disabled,0,0.01,0.03,0.05,0.1}`; the value is in utility units, not a safety certificate. Freeze configuration/checkpoints and a single primary predicted-versus-direct contrast, then run paired complete episodes on every eligible official held-out unseen scene. The primary dataset is R2R-CE; RxR-CE is a separate prespecified replication with declared languages/roles and no retuning. Other WM/actor comparisons remain secondary until executed; do not merge heterogeneous subsets into one success rate.

Report SR, SPL, nDTW, SDTW, NE, J, collisions/actions, useful/harmful overrides, STOP errors, trajectory traces and all fallbacks. Keep the same episode/random-seed pairing across methods. Evaluate three scorer/WM training seeds; if only one actor checkpoint is trained, state that actor-training variability is unmeasured. Report seed-specific outcomes as well as the aggregate.

If offline gains fail closed loop, collect new reranker-visited roots in B only, branch under the **same frozen pi_ref**, and allow one explicitly versioned occupancy-refresh experiment with unchanged C and no new unseen tuning. Do not infer that refreshed continuation labels are mathematically necessary. No repeated repair-and-peek cycle on the final unseen set.

**Scientific acceptance assumption:** for the primary predicted-versus-best-direct contrast, point ΔSR ≥2 percentage points with its 95% interval above zero, nDTW lower bound above −0.01, and no unresolved invalidity; also report ΔJ and route-fidelity effects. If utility improves but SR does not, narrow the claim to that measured tradeoff. If the upper ΔSR bound is below +2 pp, reject the prespecified practically meaningful SR claim for this setting. Otherwise inconclusive; a nonsignificant result is not equivalence. Secondary confirmatory contrasts use intervals at `1−.05/m` for m declared tests; exploratory tables remain labeled exploratory.

**Resource acceptance assumption:** profile the complete path on the actual target device, including actor/vision and KV cache, simulator graphics, WM context, all three movement predictions, VAE decode/DINO re-encoding, scorer, transfers and fallback. Record warmup separately; p50/p95 decision latency, episode wall time, policy/denoiser calls, training/collection GPU-hours, CPU RAM, CUDA allocated/reserved peaks and total-device peak. At least 100 warm decisions spanning long instructions/history plus ten whole development episodes; count OOMs and failed episodes rather than dropping them. The scoped A6 device reports 8,188 MiB: successful execution below physical capacity is required, and ≤90% total-device peak is the preferred operational headroom. A provisional lightweight target is p95 latency ≤2× the H=1 actor and superiority to a direct baseline using that same budget. These are declared engineering choices, not measured achievements or universal real-time limits. If the target fails, report the measured accuracy–cost frontier and narrow the lightweight claim; sequential/offloaded configurations are separate measured variants.

## 4. Stochastic labels, uncertainty and sample-size discipline

**Prefer a declared deterministic first protocol:** greedy actor, deterministic simulator/settings where supported, fixed prefixes and caches. Three same-seed replay matches establish integrity; distinct-seed runs test whether stochasticity remains. Deterministic branch utility is exact for that saved simulator state and continuation, not necessarily the conditional value of an observationally aliased root.

When stochasticity matters, use eight environment/continuation seeds per root/action, split into disjoint sets A and B of four. These seed sets are distinct from scene partition names. Share a valid random-seed schedule across actions to estimate paired differences, but inspect the resulting covariance: common randomness need not reduce variance. Never make imagined and real future draws share outcome information. Keep model-noise, continuation-policy, simulator, training and bootstrap PRNG streams separate and recorded. A stochastic base action is sampled once from its declared distribution per root/replicate and coupled across methods, or use its estimated expected value; substituting its mode changes the reference.

Let `Qbar_A(a)` and `Qbar_B(a)` be seed-set means and `a*_A=argmax Qbar_A(a)` with base-preserving ties. The opportunity statistic is

`G_CF = 0.5 [(Qbar_B(a*_A)−Qbar_B(a_base)) + (Qbar_A(a*_B)−Qbar_A(a_base))]`.

Selection and evaluation use independent seeds in each direction. This estimates the gain of a finite-sample branch-selection rule, **not** `max Q−Q_base`; it can be negative and must not be clipped. A direct/predicted selector is fixed independently of evaluation returns, so its paired gain uses the same independent outcome panel. For stochastic “regret,” report cross-fit reference-minus-method performance and uncertainty explicitly; do not call maximum noisy return minus selected return true expected regret. In deterministic branches, measured max-minus-selected is valid for that root. Report uncertainty around estimated Q gaps and unresolved near ties; increasing seeds cannot create more independent scenes.

For actual-next scoring, pair each feature with the outcome from its corresponding actual branch during training. In stochastic diagnostics, average actual-next scores over the selection seed panel, then evaluate the chosen action on the independent panel. This is a privileged finite-sample diagnostic of expected choice; same-panel realized-next-view selection is a different, more privileged quantity and must be labeled separately. The latter must not be compared as if it shared the predicted scorer's information set.

For predicted sampling, cross independent model-seed panels with continuation-seed panels. Evaluate whether score variation predicts real outcomes beyond root/action means; if independent noise seems to do so, audit seed/label leakage. Average **scores**, not pixels/features through a nonlinear critic, when estimating expected scores. One-sample and four-sample policies have different costs and must be evaluated separately. A3's utility-compatible `.8` versus `.9/.1` example yields `.65` under optimistic single-sample selection; its noisy equal-Q example has sampled max `.8` despite true Q `.5`. These executed counterexamples motivate the protocol, not an asserted failure frequency in CE.

**Sampling units and intervals.** Compute paired method differences within episodes, preserving all roots/actions/languages/seed panels. Report both official episode-weighted estimates and an equal-scene mean for generalization. Use a paired hierarchical bootstrap (10,000 draws, fixed seed): scenes → route clusters/episodes within scene; keep treatment pairs and seed panels together. For official fixed-scene uncertainty, additionally report episode/route-cluster intervals. Training-seed variation is reported separately; three seeds do not establish a population distribution of training runs. Show per-scene effects and scene/episode/root counts. With very few scenes, say the interval poorly represents new-scene generalization; extra root counts cannot repair this.

**Precision before power claims.** Estimate scene/episode dependence and paired-difference variance from C. Before final evaluation, simulate the proposed paired clustered design at ΔSR=0.02 and ΔU=0.01 using those development distributions; choose counts for at least 80% estimated detection probability and report assumptions/sensitivity. This calculation itself is not yet executed. If the fixed official split or resource cap cannot support it, use the full feasible split and explicitly label the result imprecise; never declare the debug sample powered. No optional stopping based on repeated unseen p-values. Each gate can end positive, meaningful-effect-excluded, invalid, or inconclusive.

## 5. Resource ledger and feasibility bounds

[Inspected execution records] A6 reran all 13 scorer groups on copied source and profiled one synthetic CPU step (eight roots, 32 observations, 256 instruction tokens): 2.44 s and 1.049 GiB peak process working set; median four-candidate scoring was 16.18 ms. These are neither CE training nor total GPU inference. A6's scoped environment has CPU-only Torch and no discoverable Habitat in the tested interpreter. CE assets/actor checkpoints and NWM weight access remain unverified; the metadata gate is not proof the user lacks approval.

[Proposed budgeting] Measure replay/continuation action counts and p95 actor-step time in E0/E1. Budget collection as `Σ(root replay steps + candidate + remaining continuation steps) × measured step cost`, plus simulator resets, feature encoding and storage; repeated seed sets multiply it. A loose B=500 debug bound is `64×4×500=128,000` counted replay/branch steps before repeats and overhead. Four-plus-four stochastic seed panels can multiply this eightfold; this is why deterministic qualification comes first. STOP has no continuation, but prefix replay still costs work. Do not cost 256 continuations as 256 images.

Initial planning caps [Assumption]: 24 GPU-hours for the first branch qualification tranche, 96 cumulative collector GPU-hours before a new resource review; two cached-scorer GPU-hours per seed/condition initially, eight maximum; a single DINO objective comparison only after gates pass. These are future budget caps, not work executed or automatically authorized in this review. Lock a concrete count plan after measured throughput; if minimum scene/episode coverage cannot fit, stop as resource-inconclusive. Reuse immutable labels/features across fair controls and run frozen components sequentially offline. No requirement to execute all twelve actor×WM combinations at once.

For the original 64-token FP16 interface, one pooled view is 48 KiB; current plus three actual and twelve predicted movement views is 768 KiB/root before histories, RGB, metadata and text/context. A6 records this arithmetic. The revised 49-token interface changes storage and must be budgeted separately. Full branch traces and actor inference dominate beyond this tensor estimate.
