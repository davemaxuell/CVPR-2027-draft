# Assignment 4 — Closest prior work and direct novelty audit

Cutoff: **2026-10-23**. Independent primary-source inspection; this is a novelty assessment, not a performance reproduction. Original approach and scorer documents were read, and the scorer's candidate evaluation, loss, selection, and label helper were inspected. No original files were changed. Full HTML papers, including available appended supplements, and four pinned official code files are archived in `../evidence/a4_sources/`; the separate ledger records retrieval and search limits.

## Decision

**The original architecture does not yet support a defensible claim of 2–3 new methodological contributions.** Predicting candidate futures, conditioning their evaluation on language/history, reranking an existing policy, learning action usefulness from simulator alternatives, and shaping dynamics for useful rankings all have close precedents. Three recent sources substantially tighten the boundary:

- **VISTAv2** already describes a frozen navigation stack augmented by action-conditioned CDiT rollouts, language scoring, candidate score fusion, first-control execution, and replanning.
- **SeekVLN** already uses simulator/context cloning and same-policy alternative continuations to measure decision benefit in VLN-CE.
- **World4Scorer** already trains candidate predictive states with simulator outcome labels and observed-future anchoring; its supplementary manipulation experiment freezes an existing world model and trains a small outcome scorer on its predicted features.

These are overlapping disclosures, not evidence that the exact proposed CE system has already been implemented. Their combination makes a broad “outcome-grounded future scorer” or “decision-aware world model” novelty claim weak. A narrower empirical research contribution remains possible: establish when action-conditioned predicted evidence improves a **fixed instruction-following primitive-action policy beyond a matched direct value model**, using identical real histories and measured alternative continuations. That contribution requires evidence not currently available.

## The actual proposal under audit

**[User specification / inspected original]** Three locked navigation backbone trials and four agreed world-model trials remain experimental options. Each trained navigation policy is frozen. For every actual prefix, the deployed system compares FORWARD, LEFT, RIGHT, STOP; only the first three need one-step predictions. An approximately 3M-parameter scorer combines instruction/context features, current patches, eight recurrent real-history slots, candidate action, and predicted next patches. It regresses a composite utility from actual first-action branches followed by the frozen reference policy to termination. The utility includes success, complete-path nDTW, remaining action count, and collisions. A held-out margin controls overrides.

**[Inspected code]** `Scorer/scorer.py:136` detaches predicted features and scores candidates independently. `scorer_loss:168` is scalar MSE plus auxiliary success/collision BCE. `select_action:181` is a margin rule. `labels.py:10` computes the supplied utility. Thus **no decision-aware dynamics training exists in the current implementation**. The approach explicitly calls that extension unfinished. Novelty cannot be credited to an unspecified future loss.

## Value-aware/task-model lineage

**[Published finding]** The general idea of fitting dynamics according to downstream value relevance predates these navigation works. [VAML, AISTATS 2017](https://proceedings.mlr.press/v54/farahmand17a/farahmand17a.pdf), §3–4, replaces a generic distributional fitting criterion with a value-sensitive model loss. [TD-MPC, ICML 2022](https://proceedings.mlr.press/v162/hansen22a.html) jointly learns task-oriented latent dynamics and terminal values for short-horizon planning; its full PDF exceeded the browser fetch limit in this audit, so this comparison is limited to the official abstract and CVAML's explicit relation.

**[Published finding]** [CVAML, ICML 2025](https://arxiv.org/html/2505.22772v2), §3 Eqs.1–2, analyzes model-predicted values against real-transition value targets; §4 and §6 distinguish deterministic models, sampling bias, calibration, and auxiliary prediction losses. Appendix A contains proofs; Appendix C supplies latent-model implementation details. [Proceedings confirmation](https://proceedings.mlr.press/v267/voelcker25a.html). Its stochastic-loss pathology is not automatically a theorem about our frozen one-sample utility scorer: the models, targets and optimization variables must first be matched.

**[Deduction]** A proposed extra loss of the form `prediction loss + value consistency`, `prediction loss + outcome loss`, or `prediction loss + pairwise action ranking` would fall inside a heavily populated design space. A new name or language token input does not establish new optimization machinery. MCR and World4Scorer are especially important direct baselines for any such extension.

## Narrow remaining opportunity and decisive tests

**[Hypothesis, not established contribution]** The potentially useful intersection is: partial egocentric CE history + full route instruction + exhaustive primitive intervention + complete actual continuation utility + a frozen navigation policy + learned predicted-view evidence. None of the inspected closest methods specifies that complete intersection. **This is not an absence proof and does not make the intersection non-obvious.** The fact that World4Scorer already carries its outcome-scoring concept across driving and manipulation increases the burden on a navigation-only adaptation.

The proposal should earn its core claim before adding methodological contributions:

1. **Candidate headroom:** measure all four actual branches from preserved policy/cache/metric prefixes. Quantify the oracle improvement and label ties. No action-choice headroom means no scorer can help at those roots.
2. **Direct-value baseline:** train the same instruction/history/action scorer without predicted views, with matched labels, parameter/optimization budget, splits and continuation policy. This is the primary rival explanation, not an optional ablation.
3. **Actual-future ceiling:** feed actual first-next features under identical labels. If this fails, improved future prediction cannot rescue this scorer/target at fixed capacity.
4. **Candidate association:** compare true predicted futures with current-view copies and within-root future/action reassignment. Measure action regret and complete closed-loop metrics, not only feature similarity. Related intervention ideas already appear in prior work, so use them as controls rather than claiming the controls themselves as inventions.
5. **Task semantics:** include valid instruction/history-stage interventions with recomputed references/outcomes. Show benefits on order/detour/STOP decisions, where the proposed whole-path target differs from distance progress. Arbitrary instruction shuffling is not ground truth.
6. **Same-family objective baselines:** if dynamics training is added, compare native prediction, direct outcome regression, value consistency, and a simple outcome-gap pairwise ranking anchor with equal capacity/data. Distinguish improvement from supervision budget or scorer retraining.
7. **Practical usefulness:** run the full closed-loop system under the actual 8 GB target and report action latency. Compare predictive auxiliary training and direct outcome policy/value alternatives. FutureNav is a primary cheaper mechanism; Assignment 1 is separately checking newer SimpleVLN/ReInsVLN alternatives.

**[Deduction]** A credible eventual paper could have one genuinely demonstrated methodological change and a complementary, carefully controlled empirical result. The current evidence does not justify committing to three new modules. If the matched direct-value model equals the future-conditioned one, retain that negative result and reconsider the world-model hypothesis rather than relabeling extra training as world-model benefit.

## Uncertainty and coverage limits

- No navigation experiment, model training, weight download, or external code benchmark was performed by this assignment.
- Recent preprints count as prior disclosures; their measured gains remain author-reported and are not treated as independent validation. The VISTAv2 protocol/supervision ambiguities materially weaken benchmark comparability, not the fact that it disclosed the architecture.
- World4Scorer's official repository was reached, but no implementation path or released checkpoint was audited before this bounded handoff. Its strongest overlap is paper/supplement evidence. The generic predictor-scorer similarity should not be overstated as exact code equivalence.
- The original sources do not provide a finalized decision-aware objective. Any later redesign must be compared afresh against the mechanisms above.
- Search followed DREAMWALKER→HNR, NWM→DINO-WM, CVAML→VAML/TD-MPC, and recent predictive navigation→VISTAv2/SeekVLN/FutureNav/WorldMAP. Additional screened leads are recorded rather than silently counted as fully reviewed evidence.
- **Final novelty verdict:** broad claims are anticipated; exact-intersection novelty remains uncertain; CVPR-level distinctiveness and empirical usefulness are **not established**.
