The coordinator's Python version is 3.13.7. Source commits, input hashes, seeds where applicable and assumptions are recorded with each test. The geometry script downloads only public connectivity JSON when its local cache is missing. No downloaded project training script is imported by that analysis.

[Environment discovery](environment.json) records the difference between the physical GPU and CPU-only PyTorch installation. [Local data discovery](local_data_inventory.json) records available annotations, subsequently acquired connectivity, and still-unestablished model/scene assets. These are resource inventories, not experiments showing navigation performance.

For reproduction, run the linked standalone Python script from the CVPR workspace or use its absolute path. Inspect its requirements and saved input manifest first. A successful rerun of these checks does not validate any proposed learned method; those methods require the distinct experiments specified in their proposals.

The [initial recovery experiment plan](Initial_Experiment_Plan.md) and [empty annotation template](recovery_annotation_template.csv) are **planned work**, not collected data. Independent evaluation artifacts retain their source versions and exact stubs so component-level execution is distinguishable from importing or running an entire navigation project.
