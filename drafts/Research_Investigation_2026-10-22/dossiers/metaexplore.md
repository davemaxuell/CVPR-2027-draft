## Problem and operating conditions

Recover from an incorrect high-level route by selecting a useful local destination in an online topological graph. The method starts from a DUET-style graph navigator and uses object-layout grounding to choose recovery goals.

## Mechanism, training, and inference

A graph cross-modal encoder feeds navigation, object grounding, progress, and mode heads. The paper calls ordinary goal-directed navigation exploration and corrective graph traversal exploitation. Mode supervision labels detours off the shortest route; a threshold of 0.5 activates recovery. Progress predicts 1 minus current/start goal distance with squared loss. A correlation regularizer, action imitation, and object grounding accompany actor-critic fine-tuning. Scene object spectra are built from category-specific binary bounding-box masks: log magnitude of a 2-D Fourier transform is vertically averaged and normalized into a K by eta representation. An instruction-derived spectrum uses an object list and average box width. Candidate recovery destinations are scored by spectrum similarity along a corrected shortest initial-to-candidate path, and the agent physically traverses the graph shortest path to the selected frontier. No future-view image is generated by this method.

## Novelty and closest predecessors

Adds instruction-conditioned object-spectrum recovery goals and learned switching to a DUET-based hierarchical agent. Spectrum grounding represents object arrangements beyond an unordered object bag, but magnitude spectra discard translation phase, and the instruction-to-object conversion does not preserve all relational language.

## Specific bottlenecks

**meta-spectrum: Object-spectrum recovery cannot uniquely determine the intended route when relational information or category distinctiveness matters.**

Conditions: Repeated objects, generic landmarks, direction-sensitive instructions, or false detections. Cause: Object lists omit some language relations and Fourier magnitude removes translation phase; mode labels operationalize shortest-path detours rather than all instruction violations.
