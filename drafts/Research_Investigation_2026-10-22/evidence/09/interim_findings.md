# Independent novelty findings — working record

Cutoff: 22 October 2026. This is an incremental record; final verdicts follow source and code inspection.

- P1: LAW (EMNLP 2021), §3, explicitly replaces shortest-goal supervision in off-path states with a language-aligned waypoint teacher, using DAgger and an unchanged recurrent CMA policy. Table 1 reports R2R-CE gains; Appendix A.6 tests RxR. Its paper's teacher is a function of current position and a reference waypoint sequence. This directly occupies the broad teacher-mismatch motivation and label-only intervention. Remaining-obligation state, semantic alternatives and set labels need comparison with its actual implementation and a straightforward reward-machine teacher.
- P2: CVS (arXiv 2603.09715v2), §2.2, filters semantic-conflict examples then prioritizes hard positives, using a frozen VLM's conditional YES/NO verdict changes. Generic validity-plus-difficulty selection is therefore already occupied outside VLN. Its scores are model-relative, whereas P2's possible distinction is independently audited clause witnesses and a controlled route-pool experiment. A standard alignment-supervised verifier is a strong alternative; witness attention is not self-certifying evidence.
- P3: Predictive state representations already represent ordered joint future tests conditioned on history/actions (Littman, Sutton and Singh, NeurIPS 2001, PDF p. 3). DiSPO and distributional successor measures additionally challenge any novelty claim from retaining branch outcomes instead of their expectation. A task-specific pair-event head is currently a restricted predictive-test representation, not a new world-model principle.
- P4: HiMeco (arXiv 2610.20312v1), §§3.1–3.4 and Appendices E–G, explicitly uses differentiated failure diagnosis and evidence eligibility to control persistent strategy/skill updates. It has nonexclusive diagnostic scores and add/revise/remove operations. Diagnosis uses privileged retrospective simulator metadata; contracts check evidence consistency, not independently certified scene truth. DoCtOR (2608.28264v1), §§3.1–3.3, already prevents misattributed failure from contaminating other agents' memories. EmbodiSkill (2605.10332v2), located through HiMeco's references, distinguishes wrong skill content from execution lapses. P4 cannot claim diagnosis before memory updates as new; claim-specific semantic-negative writes require a substantial demonstrated distinction and a deployable evidence contract.

No navigator, learned verifier, world model or project script has been executed by this assignment.
