Dataset Analysis
We examine the existence of distribution shifts across scene domains by calculating the
Fréchet Inception Distance (FID) between visual and textual features across scene domains
[6]. In Initial-instruction based CVLN (I-CVLN), 10 out of 20 scene domains are selected
randomly, and in Dialogue based CVLN (D-CVLN), 10 out of 11. We use Resnet-152 trained
on Place365 for visual feature extraction in I-CVLN [2, 9], and ViT-B/16 for D-CVLN [4].
These analyses are visualized as heatmaps in Figure 1, confirming significant visual feature
distribution shifts in both datasets. For textual features in both I-CVLN and D-CVLN, we
utilize BERT for extraction [3], with differences across scene domains examined through
FID, visualized in Figure 2.

Training Details
For training I-CVLN and D-CVLN, we adhere to training methodologies from previous
works, mixing Reinforcement Learning (RL) and Imitation Learning (IL) objectives [1, 7].
A3C is employed for RL [8], and for IL, the agent calculates cross-entropy loss for each
action by following teacher actions to traverse the ground-truth trajectory.
3
Implementation Details
We utilize transformer-based models, VLN-BERT for I-CVLN [7] and HAMT for D-CVLN
[1], with training on NVIDIA A100 GPUs. Batch size is set at 8, with 4,000 iterations per
scene domain for I-CVLN and 5,000 for D-CVLN. Image encoding employs ResNet-152
and ViT-B/16 for I-CVLN and D-CVLN, respectively [4, 5, 9].

4.1
Perplexity Replay Algorithm Pseudocode
Algorithm 1 Perplexity Replay Memory Update
1: Input: Replay memory M, replay memory size |M|, set of episodes from the last scene
domain Elast, agent parameters θ, the number of trained scene domains s
2: Output: Updated replay memory M
3: Calculate Action Perplexity (AP) for each episode in Elast and M
4: Elast ←sort(Elast,by=AP, descending)
5: M ←sort(M,by=AP, ascending)
6: ns ←|M|/(s+1)
7: for s = 1 to s do
8:
Remove episodes with the lowest AP from M for domain s until only ns episodes
remain
9: end for
10: Add episodes from Elast to M until |M| equals fixed size
11: return M

Limitation and Future Work
The Continual Vision-and-Language Navigation (CVLN) paradigm represents a initial step
forward in mitigating catastrophic forgetting through simple yet effective methods like Per-
plexity Replay and Episodic Self-Replay. However, it faces limitations in its current focus
on indoor environments and the static approach to replay memory construction and exploita-
tion. Future work should aim to expand the environmental scope to include complex out-
door settings, requiring the development of new datasets and models capable of navigating
