## M-TRACK release audit shared with assignment 04

Official repository: https://github.com/chanhee-luke/M-Track at `a7eaf93fc8631c9d1e7bbef437cc858b5b60f36a`. This is an inspectable but incomplete release, not an implementation of every paper component.

`mtrack_src/milestone.py:18–95` loads a transformer-CRF tagger and returns typed targets. `milestone/src/model/transformer_crf.py:14–43` implements decoding. `vision/alfred_head.py:31–123` supplies class-specific reachability BCE and sigmoid inference; `vnn.py:156–203` thresholds detection/reachability outputs and packs features. `env.py:106–165` prepares targets from ALFRED metadata. These establish component intent, not a working complete pipeline.

The standalone `milestone_checker.py:7–30` uses substring matching, reachable flags and the previous action. It has no persistent multi-target checklist, WordNet similarity or interaction-mask IoU. A repository-wide Python reference search found its name only in the same file. The inspected `agent.py:96–115,236–345` contains target-tagger integration TODOs and inherited CE rollout; `train.py:1–90,250–268` retains R2R paths, and `eval.py:17–89` implements graph endpoint scoring rather than the paper's ALFRED goal-condition evaluation. Both documented launchers target a missing `r2r_src/train.py`.

An executed **static parsing check** confirms a syntax error in `env.py:53`; it also records the missing launcher target and checker-reference search. See [mtrack_static_check.py](mtrack_static_check.py) and [mtrack_static_results.json](mtrack_static_results.json). Source text was parsed, never imported or executed. These findings mean the pinned release is insufficient for direct reproduction; they do not invalidate the paper's reported experiments or its prior-art significance.
