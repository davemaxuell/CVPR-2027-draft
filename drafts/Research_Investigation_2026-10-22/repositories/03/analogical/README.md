# VLN-Analogical-Reasoning

**Vision-and-Language Navigation with Analogical Textual Descriptions in LLMs**  
**EMNLP 2025 (Short Paper)**

---

## 🔧 Setup

1. Install the [Matterport3D Simulator](https://github.com/peteanderson80/Matterport3DSimulator).
2. Set up the [MapGPT baseline](https://github.com/chen-judge/MapGPT/tree/main).
3. Configure your GPT API key in [`GPT/api.py`](https://github.com/zhangyuejoslin/VLN-Analogical-Reasoning/blob/master/GPT/api.py#L11).

---

## 🚀 Inference

Run inference with GPT-4o:

```bash
bash scripts/gpt4o.sh
```
## 📝 Analogical Descriptions

During navigation, the model dynamically generates analogical visual descriptions.  For illustration, we also provide partial visual descriptions [here](https://drive.google.com/file/d/1-UA9iG6yD8Kf9btME02GrjJIdHYLOsUx/view?usp=sharing).
