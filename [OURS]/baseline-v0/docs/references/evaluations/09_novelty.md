# Assignment 09: independent novelty evaluation

Cutoff: **22 October 2026**. Evaluator: assignment 09. Scope: all four proposals in assignment 07, independently challenged through primary literature and selected official code. This is a novelty assessment, not an empirical validation or a guarantee that no closer work exists.

The original-method claim for **P3 should be rejected**. P1, P2 and P4 can remain as **conditional empirical studies**. Their broad mechanisms are established; none presently merits a strong new-method claim. The potentially valuable contributions are carefully controlled measurements and interventions that the reviewed prior work does not establish in the proposed setting. Their value depends on results that have not been obtained.

## P1: recovery labels

**09-P1-01 — LAW is the closest task-level collision.** LAW explicitly studies off-reference-path supervision and replaces a goal-directed teacher with a language-aligned waypoint teacher without requiring a new navigation architecture. Its inspected geodesic teacher selects a waypoint from current position and reference-path geometry, then returns one follower action. The active panorama configuration uses that sensor. It does not read completed-obligation history or enumerate semantically valid alternative continuations. Thus it occupies the motivation and teacher-replacement idea, but does not settle the proposed same-pose/different-completed-obligations test. [LAW, §3, PDF pp.3–4](https://aclanthology.org/2021.emnlp-main.328.pdf); [sensor, lines190–253](https://github.com/3dlg-hcvc/LAW-VLNCE/blob/020fa33a313beaf91f73add0cd62089fe768c8cf/habitat_extensions/sensors.py#L190), [configuration](https://github.com/3dlg-hcvc/LAW-VLNCE/blob/020fa33a313beaf91f73add0cd62089fe768c8cf/habitat_extensions/config/vlnce_task_law_pano.yaml).

**09-P1-02 — soft task-state prediction is already implemented.** Noisy Reward Machines separates history-based state inference from decision-making; TDM predicts a categorical belief over task states directly from history (§5.3, p.6). Official code selects a recurrent task-state detector and trains it by cross-entropy. Ground-Compose-Reinforce also composes learned grounding, automaton state and control. A DUET task-state embedding or belief head is therefore a domain adaptation of established machinery, unless a distinct learning problem and solution are demonstrated. [Noisy RM, §§4–5](https://proceedings.neurips.cc/paper_files/paper/2024/file/c71769e2715835d37c3e25cc1173bd62-Paper-Conference.pdf); [detector](https://github.com/andrewli77/reward-machines-noisy-environments/blob/af9883a1d382b8f2fe3a650faaa4fdda29d69ae1/src/detector_model.py#L8), [supervised loss](https://github.com/andrewli77/reward-machines-noisy-environments/blob/af9883a1d382b8f2fe3a650faaa4fdda29d69ae1/src/algo_pretrain_detector.py#L46); [GCR official repository](https://github.com/andrewli77/ground-compose-reinforce/tree/8f7951a529fb51bf370dbf7ae3814bf569f5c446).

**09-P1-03 — set-valued continuation supervision is not a new principle.** Optimal Completion Distillation computes all optimal next-token extensions after model-generated prefixes. Its zero-temperature target is uniform over optimal ties and uses KL; P1 instead proposes negative log probability mass on the acceptable set. Those objectives differ: the latter permits all mass on one acceptable action, whereas uniform-target KL rewards coverage of all ties. Neither the existence of multiple valid completions nor this objective substitution establishes a new navigation contribution. [OCD, §3 Eqs.(4)–(6), PDF p.3](https://arxiv.org/pdf/1810.01398v2).

**Remaining testable claim.** Independently adjudicated natural deviations contain a material subset where the same physical pose and instruction require different efficient recovery actions because different obligations have been completed. An obligation-aware teacher reduces independently judged label error and improves held-out recovery, after controlling for data, backbone, task-state information and action-set cardinality. This is a proposed empirical claim, not an established deficiency frequency.

Required comparisons are LAW-style rejoining; geometric/nDTW teachers; reversible chunk/progress tracking; a task-state-conditioned reward-machine control; one-label versus all-ties versions; and uniform-target versus marginal-set objectives. The comparison must separate better task-state inputs from better label construction. Human labels must be independent of the proposed automaton's output. Obligations should be defined only where the instruction actually requires them; a demonstration's exact route must not silently become mandatory.

**Kill gate:** if independent annotators rarely find consequential history aliasing on naturally occurring deviations, if they cannot agree on acceptable sets, or if matched LAW/chunk/RM controls explain the improvement, drop the new-method claim. A synthetic challenge set alone can support a diagnostic benchmark, not prevalence or practical importance. P1 is the strongest initial study because its premise can be tested before training a large model.

## P2: validity separated from difficulty

**09-P2-01 — valid-but-hard selection has a direct predecessor.** CVS uses a frozen VLM to filter semantic-conflict cases and then favors difficult admissible positives through conditional validity contrasts (§2.2, pp.4–5). Its domain and score are different from navigation clause witnesses, but the broad separation of useful difficulty from semantic noise is already occupied. Its YES/NO quantities are raw token probabilities; treating them as a normalized binary complement would misread the equations. [CVS v2](https://arxiv.org/pdf/2603.09715v2).

**09-P2-02 — grounding supervision and model-relative difficulty are established ingredients.** Dataset Cartography measures training confidence/variability and separately examines annotation noise, including human relabelling. FCA-NIG produces navigation sub-instruction/sub-trajectory and entity/landmark alignments through automatic generation and matching. These block claims that a two-axis score or clause-local evidence alone is novel. [Cartography, §2 and §§5–6, PDF pp.3,7–8](https://aclanthology.org/2020.emnlp-main.746.pdf); [FCA-NIG, §4.1–4.6, PDF pp.5–8](https://arxiv.org/pdf/2506.08566). GELA and the corpus's compatibility-filtering methods remain required controls; this evaluation does not replace their existing dossiers.

**Remaining testable claim.** On an unchanged navigation augmentation pool, independently adjudicated clause/transition witnesses distinguish invalid, valid and genuinely unresolved supervision from difficulty for a frozen navigator. Training on equally sized, matched subsets then tests whether this distinction has value beyond current compatibility and grounding scores. “Unresolved” must mean insufficient evidence, not automatically incorrect text. Matching one noun to one crop is not a witness for a directional or temporal relation.

Hold fixed generator outputs, environment exposure, training tokens/steps, route-length distribution and verifier budget. Include CVS adapted to trajectory evidence; global compatibility; navigator-loss/cartography selection; an alignment-trained verifier using the same labels; validity-only, hardness-only and random quota controls; and independent human-label evaluation with hidden generator identity. Count annotation and verifier costs. Test naturally generated errors separately from controlled corruptions, whose labels may be easier to infer from artifacts. Assess whether the selected set merely shifts language style or scene coverage.

**Kill gate:** drop the method claim if a grounding verifier trained on the same labels or a CVS/compatibility adaptation matches it, if witness adjudication is unreliable, or if gains disappear when pool and compute are matched. The study may still contribute a trustworthy error taxonomy and annotation resource. Novelty confidence is bounded and does not establish priority over every synthetic-data curation method.

## P3: reject the generic method claim

**09-P3-01 — ordered joint prediction already belongs to established predictive representations.** Predictive State Representations explicitly use action-conditional future observation sequences, including joint two-step tests. Horde/general value functions permit separate continuation policies, termination and terminal rewards. These directly limit a claim that ordered future events constitute a new world-model representation. [PSR, PDF pp.1,3](https://proceedings.neurips.cc/paper/2001/file/1e4d36177d71bbb3558e43af9577d70e-Paper.pdf); [Horde, §§2–4, PDF pp.2–3](https://josephmodayil.com/papers/horde-final.pdf).

The exact reduction below is this evaluator's deduction, not a theorem attributed to those papers. Let the target be

`J(k,l | h,a) = P_mu(exists i < j <= H: e_k(i)=1 and e_l(j)=1 | h,a)`.

Add a three-state event monitor: neither event completed, first event observed, ordered pair completed. Update the second-event transition using the monitor state *before* the current observation so simultaneous events do not satisfy strict order. The completed state is absorbing. Add a horizon counter, terminate at H, assign zero transient reward and terminal reward one precisely when the pair is completed. Under the same continuation policy mu, the expected terminal reward equals J by the definition of expectation of an indicator. One such predictive value can be learned for each pair. This proves representational inclusion, not learnability, calibration or benchmark usefulness.

**09-P3-02 — preserving distinct outcomes also has nearby prior art.** DiSPO models distributions over long-term feature outcomes; distributional successor measures model distributions over occupancy measures. They are appropriate branch-sensitive controls. Their ordinary occupancy features need not recover arbitrary temporal order, so they should not be used as an overstrong exact-equivalence argument. [DiSPO, §3, pp.3–4](https://arxiv.org/pdf/2403.06328); [distributional SM, Definitions3.1/3.4 and Fig.1, pp.3–5](https://arxiv.org/pdf/2402.08530).

A finite event vocabulary, pair head and VLN application could make a useful experiment. They do not by themselves justify a new-method proposal. Retain a representation audit comparing marginals, same-continuation pairs, monitor-conditioned GVFs and distributional controls, with identical continuation policies and horizon. Do not rescue P3 by renaming a predictive value function or claiming a sufficiency guarantee for a selected pair matrix.

## P4: failure-attributed negative memory

**09-P4-01 — the broad idea is already directly occupied.** HiMeco diagnoses perception/exploration/planning failures before revising persistent strategy and skill memory; its retrospective process may access privileged simulator metadata. Its evidence contracts check structured evidence linkage/consistency rather than independently certifying geometry. EmbodiSkill distinguishes erroneous skill content from execution lapses, preserving the skill body for the latter; its released code implements separate revision routing. DoCtOR attributes a decisive error before selecting which agent should reflect, explicitly motivated by avoiding contaminated memory. These are substantive collisions, not merely papers mentioning reflection. [HiMeco, §§3.1–3.4 and Apps.C.4,E–G](https://arxiv.org/pdf/2610.20312v1); [EmbodiSkill, §3.2](https://arxiv.org/pdf/2605.10332v2), [revision routing](https://github.com/air-embodied-brain/EmbodiSkill/blob/760126030eab1d33ec6a6f30988f0f1fb58df3a7/agentkit/skill/embodiskill_skill/EmbodiSkill.py#L898); [DoCtOR, §§2.2–3](https://arxiv.org/pdf/2608.28264v1).

**09-P4-02 — the proposed implementation premise is real but its harm remains unmeasured.** In the inspected PSG-Nav snapshot, when RAG collection is enabled, terminal failure adds recent detections to a negative bank; retrieval can reject future crops by similarity to that bank before positive matching. This establishes a code path, not its default activation, frequency, causal impact or a reported paper ablation. [PSG_Nav.py:1492–1563](https://github.com/Chenrf1121/psg-nav/blob/181d878ff207845a31e542a19a6592925c1e9bab/PSG_Nav.py#L1492), [rag_manager.py:277–302](https://github.com/Chenrf1121/psg-nav/blob/181d878ff207845a31e542a19a6592925c1e9bab/utils/rag_manager.py#L277).

**09-P4-03 — capability attribution itself is already studied in VLN.** CanTest defines capability-specific oracles and tests candidate attribution through counterfactual repair of a component while holding the prefix fixed. This is a relevant intervention control, not evidence of the proposed memory-writing rule. The inspected repository entrypoint only confirms task/trajectory generation; the complete oracle-repair implementation was not independently verified. [CanTest, §4.2 and App.A.4, pp.5,14](https://arxiv.org/pdf/2604.25161v1); [official publication: Findings of ACL 2026](https://aclanthology.org/2026.findings-acl.1402/).

**Remaining testable claim.** A correct semantic object detection can be assigned negative evidence because a downstream controller failed; preserving the object claim while quarantining unsupported failure-derived writes can reduce later false rejection across repeated episodes or controller changes. A proposed learned writer must outperform a simple no-negative-write or quarantine policy under the same observations and feedback. Merely replacing skill records with object records is a domain translation, not automatically a substantive new method.

Begin with logged replay or a small controlled navigation experiment: hold object identity constant, intervene on approach/completion behavior, and check whether negative records later suppress valid detections. Distinguish wrong object category from a wrong instance of the right category, inaccessible-but-correct targets, missed completion and truly false detection. Compare outcome-only writing, never-write, quarantine, observation-grounded witness rules, and attribution-guided writing. Oracle identity may diagnose the experiment but must not leak into deployment inputs or preferentially assist the proposed method.

**Kill gate:** stop before model training if false-negative bank contamination is negligible or not harmful; reject added learning if a fixed quarantine rule matches it; reject the claimed practical setting if reliable contradiction witnesses require unavailable privileged labels. Witness absence does not prove identity false, and a failure cause need not be exclusive. P4 is presently a conditional contamination study with an unproven method extension.

## Evidence status and recommendation

Start with P1's blinded recovery-label audit; run P2's fixed-pool validity audit if annotation resources permit; run P4 only after demonstrating the memory path is active and consequential. These are ranked by the ability to cheaply falsify their premises, not by invented performance forecasts. A failed pilot should change the recommendation. None has executed benchmark support.
